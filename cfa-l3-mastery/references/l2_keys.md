## 1. 数量方法（Quantitative Methods）

**考查重点**：相关与回归（一元/多元）、时间序列（趋势/AR/协整/预测）、机器学习入门、模拟（bootstrap/蒙特卡洛）。

**核心概念**
- 回归：`Yi = b0 + b1Xi + εi`；R²、调整 R²、标准误、t 检验、F 检验；多重共线性、异方差、自相关。
- 时间序列：线性/对数趋势、AR(1) `xt = b0 + b1 xt−1 + εt`；平稳性（单位根/DF 检验）；协整；样本外预测（均方误 RMSE）。
- 机器学习：监督（回归/分类）/无监督（聚类/降维）；训练/验证/测试集、过拟合、正则化、混淆矩阵、ROC。

**必背公式**
- 一元斜率 `b1 = Cov(X,Y)/Var(X)`；截距 `b0 = Ȳ − b1X̄`
- AR(1) 预测 `ŷ_{T+h} = b0/(1−b1) + b1^h (yT − b0/(1−b1))`（均值回复）
- 调整 R² = 1 − (1−R²)(n−1)/(n−k−1)

**高频坑**
- 自相关（时间序列）→ 用 Newey-West 调整标准误；异方差 → White 调整。
- AR(1) 系数 |b1|≥1 非平稳（随机游走），不可直接预测。
- 机器学习"特征工程/调参"易过拟合，需验证集防泄漏。

## 2. 经济学（Economics）

**考查重点**：汇率决定与预测、经济增长（稳态/Solow）、监管周期、国际收支、贸易与资本流动。

**核心概念**
- 汇率：相对 PPP 长期成立；利率平价（covered `F/S = (1+rd)/(1+rf)`）；汇率预测（均衡汇率法/macro 平衡/购买力）。
- 经济增长：Solow 模型；稳态储蓄率、黄金律；人力资本、全要素生产率（TFP）。
- 监管：监管周期（扩张→危机→收紧）；监管成本（合规/效率损失）与收益。

**必背公式**
- 相对 PPP：`%ΔS ≈ πd − πf`
- Covered IRP：`F = S·(1+rd)/(1+rf)`
- 稳态人均资本 `k* = (sA/((n+δ)))^(1/(1−α))`（Solow 简化）

**高频坑**
- 未抛补利率平价含风险溢价，不一定精确成立。
- 本币升值（直接标价法下 S 降）利好进口、利空出口。
- 高储蓄率提高稳态收入但**不**提高稳态增长率（增速回到 n）。

## 3. 财务报表分析（Financial Statement Analysis）

**考查重点**：养老金（DB）、跨国公司报表折算、财报质量/盈余管理、金融机构分析。

**核心概念**
- 养老金 DB：PBO（预计给付义务）、PA（计划资产）、funded status = PA − PBO；净额入表；OCI 中未确认损益/前期服务成本；DB 对比率影响（杠杆↑、ROE 初期↓）。
- 折算：现行汇率法（子公司独立功能货币，all 用期末汇率，折算调整入 OCI）vs 时态法（历史成本用历史汇率）。
- 财报质量：盈余管理（真实活动 vs 会计政策）、红警示信号（应计高、CFO 持续低于净利、激进收入确认）。
- 杜邦深化、现金转化周期。

**必背公式**
- `funded status = PA − PBO`
- `现金转化周期 = DSO + DIO − DPO`
- 折算调整（CTA）入 OCI，不影响当期净利。

**高频坑**
- 现行汇率法下全部资产/负债承受汇率风险，但权益（除留存）也折算。
- DB 计划中，discount rate↑ → PBO↓ → 费用↓、funded status 改善（敏感）。
- 经营租赁新准则下几乎所有租赁入表，破坏"表外融资"。

## 4. 公司金融（Corporate Issuers）

**考查重点**：资本结构（MM 理论、权衡、啄食顺序）、股息与回购、ESG、并购（估值/协同/换股）、公司治理。

**核心概念**
- 资本结构：MM（无税）杠杆无关；MM（有税）`VL = VU + t·D`；权衡理论（税盾 vs 财务困境）；啄食顺序（内源>债>股）。
- 股利：剩余/稳定/固定；股票回购（税法、信号、灵活性）vs 现金股利。
- 并购：协同（经营/财务）、估值方法、换股比率、并购投标策略、防御（毒丸/staggered board）。
- ESG：整合、剔除、参与；对 WACC 与估值影响。

**必背公式**
- `VL(MM有税) = VU + t·D`
- 换股比率 `ER = 目标价/收购方价`；并购溢价 = 报价/市价 − 1
- 剩余股利：先满足 NPV>0 投资，余下分红。

**高频坑**
- 资本结构影响**税盾与困境成本**，但不改变资产总价值（MM 前提：无摩擦）。
- 股票回购在资本利得税低于股利税时更优；但信号效应可能被视为股价高估。
- 协同效应须"净"协同（扣除整合成本）才创造价值。

## 5. 权益估值（Equity Valuation）— L2 核心难点

**考查重点**：DDM 家族、FCFF/FCFE、相对估值（P/E、P/B、P/S、EV/EBITDA、PEG）、私有公司估值、行业估值。

**核心概念**
- DDM：Gordon `P0 = D1/(r−g)`；两阶段/三阶段；H 模型（线性过渡增长）。
- FCFF/FCFE：无杠杆 vs 股权自由现金流；`FCFE = FCFF − 利息(1−t) + 净借入`；用 WACC 折 FCFF、用 r 折 FCFE。
- 相对估值：各倍数适用场景（P/E 盈利稳、P/B 金融/重资产、EV/EBITDA 跨资本结构、P/S 早期亏损）。
- 私有公司：规模/流动性/关键人折扣；控制权溢价。

**必背公式**
- `FCFF = EBIT(1−t) + D&A − CAPEX − ΔNWC`
- `FCFE = FCFF − Int(1−t) + NetBorrowing`
- `P0 = Σ FCFFt/(1+WACC)^t` 或 `Σ FCFEt/(1+r)^t`
- H 模型：`P0 = D0·( (r−g2) + (g1−g2)·H/2 ) / (r−g2)²`（近似）

**高频坑**
- FCFF 用 WACC、FCFE 用 r：混用即错。
- 负盈利公司不能用 P/E，用 P/S 或 EV/EBITDA。
- 倍数法结果是**相对**价值，非内在价值；需交叉验证。
- 两阶段 DDM 第二阶段增长率不能超过 GDP 长期增速。

## 6. 固定收益（Fixed Income）

**考查重点**：利差分解、MBS/ABS、信用分析、期限结构（即期/远期/期限）、久期与凸性进阶、嵌入期权债券。

**核心概念**
- 利差：基准利差、G/Z/I-spread、OAS（剔除期权）；信用利差随评级/期限/周期变化。
- MBS：过手/CMO、prepayment（PSA）、久期（负凸、紧缩风险）、OAS 定价。
- 信用：评级迁移、违约概率/回收率/LGD、信用利差与周期。
- 期限结构：即期曲线→远期；bootstrapping；收益率曲线策略（骑乘/子弹/杠铃）。
- 关键利率久期、有效久期（含权）；凸性修正。

**必背公式**
- `OAS = Z-spread − 期权价值（bps）`
- `LGD = 违约暴露 × (1 − 回收率)`
- `有效久期 = (P− − P+)/(2·P0·Δy)`（含权债用有效久期）
- 远期即期：`(1+s2)² = (1+s1)(1+f1,2)`

**高频坑**
- 可赎回债：利率下行时发行人赎回 → 投资者再投资利率下降（紧缩风险），负凸性。
- MBS 久期随利率变化非线性（prepayment 随利率反向）。
- OAS 才是可比利差，Z-spread 未剔期权。
- 信用利差扩大 → 价格跌、久期变长（低价久期长）。

## 7. 衍生品（Derivatives）

**考查重点**：远期/期货定价、互换估值、期权定价（BSM）、期权策略损益、信用衍生品（CDS）、奇异期权。

**核心概念**
- 远期/期货：持有成本模型 `F = S·e^{(r−q+c)T}`；远期价值 `Vt = St − F·e^{−r(T−t)}`。
- 互换：利率互换估值=固定腿现值−浮动腿现值；等价债券组合/FRN 组合。
- 期权：BSM（无套利、N(d1)/N(d2)）；put-call parity；希腊字母（Δ/Γ/Θ/Vega/ρ）。
- 策略：spread/combination（straddle/strangle/collar）；收益图绘制。
- CDS：信用保护买方付 premium，违约获赔付；CDS spread 近似信用利差。

**必背公式**
- `BSM call: c = S·e^{−qT}N(d1) − X·e^{−rT}N(d2)`
- `d1 = [ln(S/X)+(r−q+σ²/2)T]/(σ√T)`
- 互换价值 `Vswap = Bfix − Bfloat`
- `Δcall − Δput = e^{−qT}`（put-call parity 微分）

**高频坑**
- 远期"价值"与"价格"不同：价格=F（签约时 V=0），之后 V 随 S 变。
- 美式期权可提前行权（ dividend 影响 call）；欧式否。
- Vega 总为正（波动率↑ 期权价值↑，无论买卖权）。
- BSM 假设常数波动/无套利，对深度实值/跳空失效。

## 8. 另类投资（Alternative Investments）

**考查重点**：PE 估值与 J 曲线、房地产（直接/REIT/估值）、基础设施、对冲基金（策略/费用/尽职调查）、商品、私募 debt。

**核心概念**
- PE：估值（DCF/可比/最近交易）；VC 阶段（种子/早期/扩张/后期）；估值方法（rNPV、得分法）；J 曲线；carry 分配（European vs American waterfall）。
- 房地产：直接（cap rate、DCF、替换成本）vs REIT（NAV、P/FFO、P/AFFO）。
- 基础设施：监管资产回报（RoR）、通胀挂钩、长寿命。
- 对冲基金：策略收益来源、fee（1.5/20+）、lock-up、容量、尽职调查（历史/团队/策略/风控）。
- 商品：滚动收益、GSCCI、便利收益。

**必背公式**
- `cap rate = NOI / 价值`；`REIT NAV = (资产−负债)/股数`
- `PE 倍数法：估值 = EBITDA × EV/EBITDA`
- `AFFO = FFO − 维护性 CAPEX − 直线租金调整`

**高频坑**
- PE 估值常用 EV/EBITDA 而非 P/E（资本结构差异）。
- REIT 用 FFO/AFFO（经调整基金盈余）更真实，P/FFO 优于 P/E。
- 对冲基金净回报需扣"2/20"+费用，且流动性/容量有限。
- 商品 contango 长期损耗（滚动收益为负）。

## 9. 组合管理（Portfolio Management）

**考查重点**：资产配置、有效前沿（CAL/CML）、CAPM 与 APT、组合构建、风险管理、行为金融、Fintech。

**核心概念**
- 资产配置：SAA（长期）、TAA（战术偏离）；配置与 IPS 约束一致。
- CAPM/APT：`E(Ri)=Rf+βi(E(Rm)−Rf)`；APT 多因子 `E(Ri)=Rf+ΣβkFk`。
- 组合构建：主动份额（active share）、因子暴露、风险预算、再平衡（阈值/日历）。
- 风险管理：VaR/ES、风险因子分解、杠杆与流动性风险。
- 行为金融：认知/情绪偏差、有限套利、行为组合理论。
- Fintech：分布式账本、智能投顾、大数据/AI 在投资中的应用、监管科技。

**必背公式**
- `APT: E(Rp) − Rf = β1·F1 + β2·F2 + ...`
- `active share = 0.5·Σ|wi − wbi|`
- `ES (CVaR) = E[损失 | 损失 > VaR]`

**高频坑**
- CAPM 是 APT 单因子特例；APT 不要求市场组合。
- active share 高≠超额收益，需有 alpha 来源。
- VaR 不测尾部极端（>VaR），需用 ES 补充。
- 行为偏差导致"有限套利"——异常可部分但非完全捕捉。

## 10. 道德（Ethics）— L2 仍权重高

**考查重点**：与 L1 相同七准则，但案例更复杂（涉及研究/交易/冲突的多方情境）；GIPS 细节；责任分配。

**核心概念**
- 同 L1 七准则，但 L2 侧重**研究分析师与投资组合经理**的日常冲突（软美元、优先交易、关联交易、外部管理人与客户利益冲突）。
- GIPS：composite 必须含所有付费账户、无生存偏差、外部验证、广告合规。
- 责任权衡（ROA）：client > employer > self。

**必背**
- 软美元仅限"研究服务"且须 benefit client；经纪安排须 best execution。
- 优先交易（front-running）禁止；个人交易须 pre-clearance + 披露。
- 外部管理人：须尽调、持续监控、披露费用与冲突。

**高频坑**
- "已获客户同意"不豁免忠实义务违规（如未充分披露）。
- GIPS 复合必须含**所有**付费账户，不得选择性纳入。
- 礼物/娱乐须合规且披露，非绝对禁止。
