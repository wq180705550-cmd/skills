# CFA Level 1 各科目要点提炼（Key Points）

> 本文件为 CFA L1 十个科目的结构化要点提炼，基于 CFA 官方考纲权威知识体系编写（即各位讲师讲义的来源）。

## 1. 道德与职业准则（Ethics & Professional Standards）— L1 权重最高(~15–20%)

**考查重点**：七大准则（Standards of Professional Conduct）的识别与情境应用；GIPS 概念；勉强合规（ethics vs compliance）。

**核心概念**
- 七准则：专业性 / 对资本市场诚信 / 对客户责任 / 对雇主责任 / 投资分析/建议/行动 / 利益冲突 / 责任与适用性。
- 关键区分：**忠实义务 vs 谨慎义务**；**软美元**（仅用于研究，须 benefit client）；**礼物/娱乐**（须合理、披露、合规）。
- **处罚框架**：分析事实 → 适用准则 → 是否违规 → 整改建议。

**必背**
- Standard I(A) 知识了解：内幕信息（MNPI）禁止利用/传递；重大非公开信息的"合理预期会影响价格"。
- 重大性原则：仅 material + nonpublic 才构成内幕信息违规。

**高频坑**
- 把"合规"误当"道德"——合规是底线，道德要求更高。
- 混淆 fiduciary duty 与 prudence（现代组合理论视角）。
- 实务题中"已披露即合规"未必成立（仍可能违反忠诚义务）。

**→ 网盘资料**：`l1_materials.md` §道德与职业准则（★ 2025 品职框架图 + 王者百题_道德）

## 2. 数量方法（Quantitative Methods）

**考查重点**：货币时间价值（TVM）、统计描述、概率、分布、抽样、假设检验、相关性。

**核心概念**
- TVM：N / I/Y / PV / PMT / FV；EAR vs 复利；年金（普通/期初/永续）。
- 描述统计：均值/中位数/众数、方差/标准差、偏度（正偏右尾长）、峰度。
- 概率：加法/乘法、条件概率、贝叶斯、排列组合、ROI/夏普等衍生。
- 推断：置信区间、单样本 t 检验、Type I（α）/II（β）错误、p 值。

**必背公式**
- `EAR = (1 + r/m)^m − 1`
- `σ² = Σ(x−μ)²/n`（总体）/`s² = Σ(x−x̄)²/(n−1)`（样本）
- 协方差 `Cov(X,Y)=E[XY]−E[X]E[Y]`；相关系数 `ρ = Cov/σxσy`
- 置信区间 `x̄ ± t*(s/√n)`
- 几何平均收益 `Rg = (Π(1+Ri))^(1/n) − 1`（用于多期复合）

**高频坑**
- 偏度方向：正偏 = 均值 > 中位数 > 众数，右尾长。
- 样本方差分母是 n−1，总体是 n。
- p 值 < α → 拒绝 H0；Type II 错误在 H0 为假时未拒绝。

**→ 网盘资料**：`l1_materials.md` §数量方法（★ 2025 品职框架图 + 王者百题_数量）

## 3. 经济学（Economics）

**考查重点**：供需、弹性、微观结构、宏观指标、IS-LM/AD-AS、货币政策与财政政策、汇率基础、贸易。

**核心概念**
- 弹性：需求价格弹性 `Ed = %ΔQ/%ΔP`；交叉弹性（替代品正、互补品负）；收入弹性。
- 宏观：GDP 三种核算、失业类型（摩擦/结构/周期）、通胀（CPI、核心通胀）、菲利普斯曲线。
- 政策：扩张/紧缩货币与财政；乘数效应；挤出效应。
- 汇率：绝对/相对购买力平价（PPP）、利率平价（covered interest parity）、国际收支。

**必背公式**
- 交叉弹性 `Exy = %ΔQx/%ΔPy`
- 货币中性长期：货币供给↑ → 价格↑、实际变量不变。
- 实际汇率 `real = nominal × (Pforeign/Pdomestic)`

**高频坑**
- 短期菲利普斯曲线向下倾斜，长期垂直（自然失业率）。
- 未预期通胀有利于债务人、损害债权人。
- 扩张财政 + 紧货币 → 利率↑、挤出私人投资。

**→ 网盘资料**：`l1_materials.md` §经济学（★ 2025 王者百题_经济 + 品职框架图）

## 4. 财务报表分析（Financial Statement Analysis, FSA）

**考查重点**：四表勾稽、收入确认、存货（FIFO/LIFO）、长期资产折旧摊销、债券/租赁、比率分析、GAAP vs IFRS 差异。

**核心概念**
- 三大报表：资产负债表（A=L+E）、利润表、现金流量表（经营/投资/筹资）。
- 收入确认（IFRS 15 / ASC 606 五步法）：识别合同→履约义务→交易价→分摊→确认。
- 存货：FIFO（通胀下 COGS 低、利润高、税高）；LIFO（相反）；LIFO reserve 转换。
- 折旧：直线 vs 加速；资本化 vs 费用化对利润/现金流影响。
- 比率：流动性、偿债、经营效率、盈利（毛利率/EBITDA/ROE 杜邦）、估值倍数。

**必背公式**
- `杜邦 ROE = 净利润率 × 总资产周转 × 权益乘数`
- `存货周转 = COGS / 平均存货`；`应收周转 = 营收 / 平均应收`
- `利息保障倍数 = EBIT / 利息`
- LIFO→FIFO 利润调整：`FIFO 净利 = LIFO 净利 + ΔLIFO reserve × (1−t)`

**高频坑**
- LIFO 在 IFRS 不允许；US GAAP 允许。
- 经营租赁（新准则下）入表 → 资产、负债同时上升，初期 ROE/ROA 下降。
- 资本化利息降低当期费用、虚增利润，但经营现金流不变。

**→ 网盘资料**：`l1_materials.md` §财务报表分析（★ 2025 王者百题_财报 + 品职 FRA 框架图）

## 5. 公司金融（Corporate Issuers）

**考查重点**：公司治理、资本预算（NPV/IRR）、WACC、股利政策、ESG、资本结构基础。

**核心概念**
- 公司治理：董事会、代理问题、股东权利、利益相关者。
- 资本预算：NPV（>0 接受）、IRR（> 要求回报接受）、回收期、盈利指数。
- WACC：`WACC = wd·rd(1−t) + we·re`。
- 股利：剩余股利、稳定/固定、股票回购 vs 现金股利（税与信号效应）。

**必背公式**
- `NPV = Σ CFt/(1+r)^t − 初始投资`
- `WACC = (D/V)rd(1−t) + (E/V)re`
- 永续增长模型 `re = D1/P0 + g`

**高频坑**
- NPV 与 IRR 在非常规现金流/互斥项目可能冲突 → 以 NPV 为准。
- 资本预算用**增量现金流**、税后、含机会成本，忽略沉没成本。
- 股票回购与现金股利对价值中性（完美市场），但税/信号不同。

**→ 网盘资料**：`l1_materials.md` §公司金融（品职框架图 + 强化班讲义）

## 6. 权益投资（Equity Investments）

**考查重点**：证券市场结构、指数构建、权益证券估值基础（DDM、P/E）、行业与公司分析、EPS/PEG。

**核心概念**
- 市场结构：一级（IPO）/二级、做市商 vs 指令驱动、买/卖价差。
- 指数：价格加权（道指）、市值加权、等权；再平衡与调整。
- 估值入门：Gordon 增长 `P0 = D1/(r−g)`；PEG = PE/g。
- 行业分析：生命周期、Porter 五力、外部影响因素。

**必背公式**
- `P0 = D1/(r−g)`（Gordon，要求 g < r）
- `PEG = (P/E) / g%`
- 可转债/优先股估值入门（DDM 变体）

**高频坑**
- 价格加权指数受高价股影响大；拆细需调整除数。
- Gordon 模型对 g 极敏感，g 不可≥r。
- 市值加权存在"追涨"偏差（价格偏离内在价值）。

**→ 网盘资料**：`l1_materials.md` §权益投资（品职框架图 + 百题）

## 7. 固定收益（Fixed Income）

**考查重点**：债券定价、收益率、久期、利差、期限结构、风险（利率/信用/流动性/赎回）。

**核心概念**
- 定价：`P = Σ CFt/(1+y)^t`；平价/溢价/折价与票息 vs YTM 关系。
- 久期：Macaulay、修正久期 `ModDur = MacDur/(1+y)`；近似久期公式。
- 收益率曲线：即期/远期、水平/陡峭/平坦/倒挂；预期/流动性偏好/市场分割理论。
- 利差：G-spread、I-spread、Z-spread、期权调整利差（OAS，含赎回）。

**必背公式**
- `近似久期 = (P− − P+) / (2·P0·Δy)`
- `久期法则：ΔP/P ≈ −ModDur·Δy`
- `远期利率 f = [(1+s2)^2/(1+s1)] − 1`（年化）

**高频坑**
- 久期衡量利率风险，凸性修正大波动；负凸性资产（可赎回）利率下行获益少。
- YTM 假设再投资利率=YTM，现实中不成立（仅零息债精确）。
- 通胀挂钩债券（TIPS）本金随 CPI 调整。

**→ 网盘资料**：`l1_materials.md` §固定收益（品职框架图 + 百题）

## 8. 衍生品（Derivatives）

**考查重点**：远期/期货/互换/期权基础、定价与收益结构、对冲应用。

**核心概念**
- 远期/期货：无套利 `F = S·e^{(r−q)T}`；期货逐日盯市。
- 期权：call/put、内在价值+时间价值；到期 payoff；实/平/虚值。
- 互换：利率互换（固定换浮动）、货币互换、权益互换。
- 对冲：用远期锁定价格；用期权获得下行保护且保留上行。

**必背公式**
- `F = S·e^{(r−q)T}`
- 看涨期权下限 `c ≥ max(0, S − Xe^{−rT})`；看跌 `p ≥ max(0, Xe^{−rT} − S)`
- put-call parity：`c + Xe^{−rT} = p + S`

**高频坑**
- 远期与期货定价相同，但期货有盯市现金流、税/违约差异。
- 卖出期权最大收益有限、损失可能巨大。
- 基差风险：对冲工具与标的非完全相关。

**→ 网盘资料**：`l1_materials.md` §衍生品（品职框架图 + 百题）

## 9. 另类投资（Alternative Investments）

**考查重点**：对冲基金、私募股权、房地产、大宗商品、基础设施的特征、收益来源、费用、流动性。

**核心概念**
- 共同特征：低流动性、高门槛、弱监管、分散化潜力。
- 对冲基金：策略（LS、宏观、CTA、事件、相对价值）；费用"2/20"；lock-up。
- PE：VC/并购；J 曲线（早期负回报）；GP/LP、carry。
- 房地产：直接 vs REIT；NOI、cap rate `cap = NOI/价格`；杠杆效应。
- 商品：滚动收益、contango/backwardation、通胀对冲。

**必背公式**
- `cap rate = NOI / 资产价格`
- `杠杆回报放大：ROE ≈ 资产回报 + (资产回报−融资成本)× 负债/权益`
- 夏普相关：另类常提供低相关分散收益。

**高频坑**
- 对冲基金收益"2/20"吞噬显著，需看净收益。
- PE J 曲线：前期管理费+投资亏损，后期增值。
- 商品 contango 时滚动收益为负（贴水损耗）。

**→ 网盘资料**：`l1_materials.md` §另类投资（品职框架图 + 百题）

## 10. 组合管理（Portfolio Management）

**考查重点**：风险与收益、资产配置、有效前沿、CAPM、组合构建、行为偏差入门。

**核心概念**
- 收益度量：持有期、算术/几何平均、货币加权（MWR）vs 时间加权（TWR）。
- 风险：方差/标准差、下行风险；相关性降低组合风险。
- 有效前沿：最小方差组合、CAL、CML；CAPM `E(Ri)=Rf+βi(E(Rm)−Rf)`。
- 资产配置：战略 SAA vs 战术 TAA。

**必背公式**
- `组合方差 = w1²σ1² + w2²σ2² + 2w1w2ρσ1σ2`
- `CAPM: E(Ri) = Rf + βi[E(Rm) − Rf]`；`β = Cov(Ri,Rm)/Var(Rm)`
- `Sharpe = (Rp − Rf)/σp`

**高频坑**
- TWR 剔除现金流影响，比较基金经理表现用 TWR；MWR 反映投资者实际。
- 分散化降低非系统风险，不消除系统风险。
- 两资产组合风险最低点未必是等权，取决于相关性与波动。
