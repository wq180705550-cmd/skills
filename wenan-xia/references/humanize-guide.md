# 文案虾 — 去 AI 味润色指南

本文件定义「润色优化」步骤的具体改写手法。**优先调用环境内置 Humanizer**；
若不可用，按本指南由 LLM 直接润色，效果等价。

---

## 零、调用策略（双路兜底）

1. **优先**：若 WorkBuddy 环境内置 `Humanizer` 工具/技能可用，调用它去除 AI 痕迹。
2. **兜底**：若 `Humanizer` 未连接或调用失败，由 LLM 严格按下方「一~三」手法逐句改写。
   > 判断方式：尝试一次轻量 Humanizer 调用；捕获「工具不存在 / 未授权」等错误时，
   > 立即切换本指南路径，并向用户说明"已用内置润色规则兜底"。

---

## 一、词汇层（替换套路词）

| AI 高频词 | 改为 |
|----------|------|
| 首先 / 其次 / 最后 / 综上所述 | 删掉，用内容自然过渡；或「一来」「再说」「关键是」 |
| 在当今社会 / 随着…发展 / 在…背景下 | 直接删，开篇不铺垫 |
| 毋庸置疑 / 显而易见 / 不可忽视 | 用具体事实替代，或删 |
| 总而言之 / 总的来说 | 删，结尾用金句 |
| 重要的一点 / 值得注意的是 | 删，直接说事 |
| 我们将 / 让我们 | 改「你」或陈述句 |
| 旨在 / 致力于 / 赋能 / 抓手 / 闭环 | 业务黑话，全删，说人话 |
| 不仅…而且 / 一方面…另一方面 | 非必要不写对仗，拆成两句 |

**原则**：一段里出现 ≥2 个上表词，必改。

---

## 二、句式层（打破模板）

1. **长短交错**：连续 3 个以上长句（>25字）后，插 1 个短句（<10字）断节奏。
2. **破总分总**：AI 爱写"总—分—总"。改为"分—分—点题"或"钩子—分—收"。
3. **加口语连词**：「说白了」「其实」「你想」「说到底」用在转折/解释处，一次一篇≤3处。
4. **设问替代陈述**：把"XX 很重要"改成"XX 到底重不重要？"再答。
5. **删冗余过渡段**：「接下来我们看一下」「下面进入正题」这类纯过渡句全删。

---

## 三、结构层（去整齐感）

1. **段落不齐**：不要每段 3–4 句整齐划一。有的 1 句，有的 6 句。
2. **留白**：小红书/公众号在清单项之间空行；不在视觉上堆满。
3. **具体锚点**：每段至少有一个具体名词（人名/品牌/数字/场景），不飘在概念层。
4. **一个意外**：全文放 1 处反常识/反直觉的点，打破"正确但无聊"的 AI 腔。

---

## 四、润色自检清单（交付前过一遍）

- [ ] 删光了「首先/其次/最后/综上所述/在当今社会」
- [ ] 开篇 ≤3 句入题，无铺垫
- [ ] 没有连续 3+ 长句无短句断点
- [ ] 没有业务黑话（赋能/抓手/闭环）
- [ ] 每段至少一个具体名词/数字
- [ ] 结尾是金句或行动召唤，不是"希望对你有帮助"

> 若走了 Humanizer 工具路径，上述清单仍作为**验收标准**——工具输出也要过这 6 条。
